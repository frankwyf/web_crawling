# v0.2.0 — Reliable local use and verified packages

This release makes the project easier to install, explore offline, recover from data failures and maintain across operating systems.

- **Offline onboarding:** `web-crawling demo` builds a searchable index and report from bundled HTML. `--version` is available from the console and module entry points.
- **Protected data:** complete sibling-file writes precede index/report replacement. A zero-page crawl preserves the old index. Index validation rejects malformed postings before changing loaded state.
- **Predictable commands:** file-backed commands read the requested index; operational failures return status 1 and write a concise stderr error. Invoking the CLI without arguments starts the interactive shell correctly.
- **Working sitemap XML:** flat URL sets use the standard library, removing an undeclared optional-parser requirement.
- **Content query pages:** pagination/content query parameters remain distinct while common tracking fields are removed, preserving sync/async regression coverage from the preceding query fix.
- **Dependency security:** Requests 2.34.2 and Flask 3.1.3 replace versions with known advisories; a strict pip-audit job gates package and release jobs.
- **Verified distribution:** Linux Python 3.10–3.12 and macOS/Windows Python 3.12 tests; fresh wheel installations on all three operating systems; bundled template/static/corpus checks; release version checks and SHA256SUMS.
- **Contributor guidance:** updated quick starts, storage setup scripts, architecture, index/API contracts, release process and an explicit maturity roadmap.

## Compatibility and limits

Existing index field names, search responses and Quotes profile remain supported. Structurally invalid historical indexes now fail validation and should be backed up and rebuilt. Scripts can now rely on nonzero CLI failures. Atomic replacement is per file; index and report are not one transaction.

The project remains pre-1.0 and intended for local, trusted, small authorized crawls. Automatic robots enforcement, async retry/rate-limit parity, pre-request redirect restrictions, recursive sitemap indexes and multiple isolated app datasets are future work. This release publishes GitHub assets; it does not configure PyPI or a public deployment.

[Local before/after validation evidence](v0.2.0-validation.md): 70 → 98 passing tests, 74% → 78% branch coverage, offline replay and installed-wheel checks.
