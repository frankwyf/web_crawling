The initial 18 new tests failed on the baseline implementation. Fixes were then verified using fixtures and Mocks. Review added three further reproductions for identical output paths and stale query caches; those now pass. The tests prohibit external DNS resolution and non-loopback socket connections. No live websites were crawled.

Local source and wheel builds passed using existing build tools without isolation downloads. The wheel was installed into a separate external-SSD target directory with existing dependencies. The smoke script ran outside the checkout and checked installed metadata, the console/module/legacy entry points, offline demo, expected command failures, Flask test-client routes, search results, templates and stylesheet. A mismatched tag was rejected; the matching tag generated SHA256SUMS. The source archive also contains storage setup scripts, benchmark sample and bundled HTML.

The local wheel check reuses existing dependencies. Separate CI package jobs install declared dependencies into fresh environments on Linux, macOS and Windows. A strict pip-audit job additionally scans CI dependencies; its service calls are separate from offline feature tests. Publication reuses all these gates and validates the tag against both artifacts.

Timings are small local query-replay measurements, not a statistically established speedup or a crawl-performance benchmark. No crawler/ranking performance refactor was made. Dependency advisory results are time-specific and do not establish application security. See the roadmap and index-format contract for unimplemented behaviors and persistence limits.
